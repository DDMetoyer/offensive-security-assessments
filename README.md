# Offensive Security Assessments

Red-team engagement reports and security analysis write-ups.

## Contents

### [CyberApolis Water — Red Team Assessment](cyberapolis-water-pentest/)
A full-chain penetration test against a simulated municipal water utility on an isolated cyber range. Covers OSINT reconnaissance, Nmap and OWASP ZAP scanning, exploitation of OS command injection and SQL injection, and post-exploitation credential access, with prioritized mitigations mapped to NIST SP 800-115 methodology.

### [Wireless Security Labs](wifi-security-labs/)
Hands-on WiFi security studies with a Hak5 WiFi Pineapple: what passive reconnaissance leaks, why unauthenticated management frames enable denial-of-service, and the limits of MAC filtering, each paired with concrete defenses (WPA3, 802.11w, segmentation).

### [Network Protocol Analysis](network-protocol-analysis/)
Three short analysis papers:
- **Network protocol vulnerabilities and defenses** — UDP flooding, DNS amplification, spoofing and mitigations
- **Wireless attacks and mitigation strategies** — man-in-the-middle and eavesdropping
- **Tracing a packet through the layers** — a walkthrough of the OSI / TCP-IP stack using an everyday email

## Note on scope

Every engagement here was conducted against simulated environments or my own equipment, under authorization. The reports are written to demonstrate methodology and defensive recommendations. Sensitive details (real-format identifiers, other people's data captured incidentally) have been redacted.
